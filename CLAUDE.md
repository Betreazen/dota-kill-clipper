# dota-kill-clipper — правила для Claude Code

## Перед началом любой работы
1. Прочитай `docs/MEMORY.md` (решения, открытые вопросы, журнал) и `docs/PLAN.md` (текущая фаза).
2. Не начинай код, пока спека в `docs/PROJECT.md` не помечена как **утверждена** пользователем.
3. Пиши по-русски в документах и общении; код и комментарии в коде — по-английски.

## Процесс (spec-pilot + superpowers)
- Порядок: интервью → спека → явное «да» → реализация (TDD) → верификация → ревью.
- Никаких параллельных саб-агентов без утверждённой спеки.
- Перед сдачей: опиши, как проверишь результат, затем реально запусти проверку (тесты / OBS / ffmpeg) и покажи вывод.
- Стиль кода: ponytail/karpathy — минимально, стандартная библиотека прежде зависимостей, без спекулятивных абстракций.

## Зоны человека (не делать без явного запроса)
- Удаление записей/клипов пользователя, изменение профиля OBS, `git push`, публикация репозитория.

## После значимых шагов
- Обнови `docs/MEMORY.md` (журнал + решения) и отметь пункты в `docs/PLAN.md`.
