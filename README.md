# dota-kill-clipper

Автоматическая нарезка клипов с убийствами из Dota 2 во время записи в OBS.

Идея: включаешь запись в OBS, играешь. Каждое твоё убийство (или серия убийств в одном бою)
автоматически сохраняется отдельным клипом в папку матча: `10 с до первого убийства … ~10 с после последнего`,
минимум 20 секунд на клип. Источник событий — Dota 2 Game State Integration (GSI), пакеты каждые 0.1–0.5 с.

**Статус:** этап интервью и спецификации. Кода ещё нет.
