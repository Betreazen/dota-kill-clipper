Читать первым при возобновлении работы. Обновлять после каждого значимого шага.

## Суть задачи (одним абзацем)
OBS-плагин для Dota 2: во время записи автоматически сохранять клипы с моими убийствами (10 с до первого убийства,
хвост после последнего, серия = один клип, минимум 20 с, ждать 5 с после последнего убийства серии), раскладывать по папкам
матчей с именами вида `[00.23.37-00.23.57] 1 kill (KDA 3-1-2).mp4`. Корневую папку задаёт пользователь в интерфейсе плагина.
События берём из Dota 2 GSI (рост `player.kills`).

## Грабли реализации
- В Python 3.12 для OBS нет пакета `tzdata`: `ZoneInfo("Europe/Minsk")` падает. `publishing.zone()` откатывается на фиксированный UTC+3 (в Беларуси нет летнего времени); сброс квоты YouTube считается как 08:05 UTC без базы поясов.
- Нативный декодер VP9 в ffmpeg теряет альфу: для `.webm` нужен `-c:v libvpx-vp9` перед `-i`. DNxHR 444 альфу не хранит; рабочий формат CTA — ProRes 4444 (`yuva444p12le`).
- Описание YouTube ограничено 5000 **байтами**: русский текст занимает ~2 байта на символ. Больше 60 хештегов — YouTube игнорирует все.
- OAuth-приложение Google в статусе Testing выдаёт refresh token на 7 дней — перевести в In production.
- В заглушке YouTube для тестов нельзя называть поля как ресурсы API (`videos`, `playlists`) — они перекрывают методы.
- Git Bash выводит кириллицу из Python кракозябрами — запускать с `PYTHONIOENCODING=utf-8`.
- 13.09 рабочий поток резки упал с `TypeError` (другой ИИ передал `vertical` позиционно в `run`); исключение не ловилось, клип завис в «cutting», файл буфера 760 МБ остался в `D:\Material\Obs записи`. Теперь любой сбой резки пишется в `match.json` как `error`.
- `install.ps1` для Windows PowerShell 5.1 обязан быть UTF-8 **с BOM**, иначе кириллица ломает парсер.
- Правка файлов конфигурации OBS (`%APPDATA%\obs-studio\user.ini`, scene json) из сессии запрещена классификатором — регистрация скрипта только руками через GUI.
- Heredoc в Bash-инструменте ломается на Python-строках с `'` и `%` — тесты писать через Write.
- В 3.12 для OBS нет pytest; проверять там `python.exe -c "import killclipper.*"` (тесты гоняются на 3.14).
- `ffprobe`/`ffmpeg` из OBS запускать с `CREATE_NO_WINDOW`, иначе мигают консольные окна.
