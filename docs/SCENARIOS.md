# SCENARIOS — сценарии использования и вопросы

## 1. Основные сценарии

### S1. Обычный матч, одиночное убийство
1. Запускаю OBS, жму «Начать запись». Плагин видит старт записи → включает replay buffer.
2. Захожу в матч. GSI начинает слать пакеты, плагин узнаёт `matchid`, героя, время.
3. В 23:37 убиваю врага: `player.kills` 2 → 3.
4. Плагин запускает окно ожидания серии. Новых убийств нет → по истечении окна + хвоста сохраняет буфер,
   режет клип `[23:27; 23:47]` (10 с до, 10 с после = 20 с) → `…\<матч>\[00.23.27-00.23.47] 1 kill (KDA 3-1-2).mp4`.

### S2. Серия убийств в одном бою
1. Убийства в 31:02, 31:15, 31:33 (двойное в одном пакете тоже возможно).
2. Каждое новое убийство продлевает окно. После 31:33 новых нет → ждём хвост + 5 с → клип `[30:52; 31:43+]`.
3. Имя: `[00.30.52-00.31.43] 3 kills (KDA 6-1-4).mp4`.

### S3. Матч без убийств
- Папка матча: создавать при старте матча (пустая папка = «я играл, но без убийств») или не создавать вовсе? → вопрос Q7.

### S4. Запись OBS не включена
- Убийство случилось, а записи нет → буфер не работает → плагин пишет в лог «нет записи, клип пропущен»
  и (опционально) показывает уведомление. Или буфер повтора включать всегда при запуске OBS, независимо от записи? → вопрос Q9.

### S5. Несколько матчей за одну запись
- Между матчами `matchid` меняется → новая папка. Запись OBS одна и та же — с replay buffer это не проблема.

### S6. Реконнект / OBS запущен посреди матча
- Первый пакет GSI — базовый, дифф не делаем (kills=5 при старте ≠ 5 убийств). Проверено в d2pt.

### S7. Пауза в игре
- Во время паузы `map.paused = true`, таймер стоит. Если убийство было прямо перед паузой, хвост «по игровому времени»
  растянется; считать хвост по реальному времени (wall clock), а не по `clock_time` — иначе клип получит лишние секунды экрана паузы.

## 2. Краевые случаи
| Случай | Поведение |
|---|---|
| Убийство до рога (clock_time < 0), напр. первая кровь на -0:30 | Имя `[-00.00.40--00.00.20]` некрасиво → показывать `pre 00.00.40`? Решить при реализации |
| Бой длиннее буфера повтора | Клип обрезается по началу буфера; в лог предупреждение; рекомендуем буфер 90–120 с |
| Дабл-килл в одном пакете (kills +2) | Считается серией из 2 |
| Демо-режим / боты (`matchid` = 0) | Папка `demo <дата время> <герой>` — полезно для теста |
| GSI не приходит (cfg не установлен, порт занят) | Индикатор в панели скрипта: «GSI: нет пакетов N с» |
| ffmpeg не найден | Клип остаётся «сырым» файлом буфера с пометкой `_raw` + запись в лог |
| Диск заполнен / нет прав на папку | Ошибка в лог и в панель, запись OBS не трогаем |
| Два GSI-конфига на одном порту | Наш cfg на своём уникальном порту (напр. 3220) |
| Пользователь выключил OBS во время серии | Клип потерян; буфер сохраняется только по команде |

## 3. Вопросы пользователю (нужны ответы до спеки)

**Q1. Форма «плагина».** (а) Python-скрипт внутри OBS (Tools → Scripts, настройки прямо в OBS) — потребует поставить Python 3.12 x64
рядом с 3.14 (OBS 32 заявляет поддержку 3.6–3.12); (б) отдельная программа на Python 3.14 + obs-websocket (нужно один раз включить
websocket-сервер в OBS, настройки в своём окошке). Моя рекомендация: (а), если не против поставить Python 3.12.

**Q2. Откуда брать видео.** (а) Replay buffer — клип готов через ~15 с после боя, нужно поднять лимит буфера в OBS
(длина ~90–120 с, память ~1.5 ГБ; плагин может включать буфер сам); (б) резать из готового файла записи после закрытия файла
(у тебя split каждые 15 мин → задержка до 15 мин, бои на стыке файлов). Рекомендация: (а).

**Q3. Тайминги.** Уточни цифры: до первого убийства — 10 с; хвост после последнего убийства — 10 с (чтобы одиночное = 20 с)?
Окно, в течение которого следующее убийство считается той же серией — 15 с? И «+5 с после последнего убийства серии» — это
дополнительная задержка перед сохранением (клип всё равно заканчивается через 10 с после последнего убийства) или клип серии должен быть
на 5 с длиннее (хвост 15 с)?

**Q4. Что считать событием.** Только мои убийства (`player.kills`)? Нужны ли клипы моих смертей и/или ассистов (отдельно или в тот же клип)?

**Q5. Папки и имена.** Предложение: папка `2026-09-09 21-35 pudge (match 8954164528)`, клип `[00.23.27-00.23.47] 1 kill (KDA 3-1-2).mp4`,
плюс `match.json` с деталями. Оставить, или убрать KDA / сменить порядок / имя героя по-русски?

**Q6. Качество и точность резки.** (а) `-c copy` — мгновенно, без потери качества, границы ±1–2 с по ключевым кадрам;
(б) перекодирование NVENC — точные границы, чуть медленнее. Рекомендация: (а) с запасом ±2 с.

**Q7. Папка матча.** Создавать при входе в матч (будут пустые папки за игры без убийств) или при первом убийстве?

**Q8. Корневая папка по умолчанию.** `D:\Material\Obs записи\Dota kills`? (меняется в интерфейсе)

**Q9. Когда включать буфер повтора.** Только пока идёт запись OBS (как ты описал: «я начинаю запись») или всегда, пока открыт OBS,
чтобы клипы падали даже без полной записи?

**Q10. GitHub.** Создать приватный репозиторий на github.com/Betreazen и запушить, или оставить только локальный git?
