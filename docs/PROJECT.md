# PROJECT — dota-kill-clipper

Статус спеки: **утверждена 2026-09-09** (пользователь запросил сессию реализации, точка входа — `docs/START_PROMPT.md`).

## 1. Цель
OBS-скрипт, который без ручного монтажа сохраняет короткие клипы с моими убийствами и ассистами в Dota 2.
Работает через буфер повтора OBS: полная запись экрана не нужна, достаточно открытого OBS с запущенным буфером.

## 3. Источник событий: Dota 2 GSI
Скрипт поднимает HTTP-приёмник на `127.0.0.1:3220` и ставит cfg
`…\dota 2 beta\game\dota\cfg\gamestate_integration\gamestate_integration_killclipper.cfg`
(`throttle 0.1`, `buffer 0.1`, данные `provider`, `map`, `player`, `hero`, токен генерируется при установке).
Путь Dota ищем через реестр Steam + `libraryfolders.vdf` (как в `dota-helper-app/d2pt/gsi_config.py`).

Событие = рост `player.kills` или `player.assists` между пакетами при `map.game_state` ∈ {`PRE_GAME`, `GAME_IN_PROGRESS`}.
Первый пакет матча — базовый (дифф не делаем: реконнект/поздний старт OBS). `matchid` = 0 (демо/боты) — папка `demo …`.
Напоминание: параметры запуска `-console -condebug -conclearlog` дают `console.log`, для плагина не нужны.

## 4. Алгоритм серии и клипа
```
событие (kill/assist) в момент t (wall clock) с clock_time c
  если серии нет → серия {first=t, first_clock=c, last=t, last_clock=c, events=[…]}
  иначе, если t − last ≤ 15 с (окно) → last=t, добавить событие
  иначе → закрыть старую серию (ниже), открыть новую
таймер: серия закрывается, когда прошло max(окно 15 с, хвост) после last без новых событий
  хвост = 10 с, если событий 1; 15 с, если ≥ 2
  → obs_frontend_replay_buffer_save()
  → по OBS_FRONTEND_EVENT_REPLAY_BUFFER_SAVED: path = obs_frontend_get_last_replay(), saved_at = now
  → ffmpeg: start = dur − (saved_at − (first − 10 с)), end = dur − (saved_at − (last + хвост)), -c copy
  → имя по clock_time: [first_clock − 10 с; last_clock + хвост], N kills / assists, KDA после серии
```
Хвост и окно считаются по реальному времени (пауза в игре не растягивает клип).
Минимальная длина клипа 20 с выполняется автоматически (10 + 10). Длина буфера в OBS: 120 с, лимит памяти 2048 МБ
(скрипт выставляет через profile config, если значения меньше; пишет в лог, что изменил).
Если бой длиннее буфера — клип обрезается по началу буфера, предупреждение в лог.

## 5. Именование
- Папка: `<Корень>\<YYYY-MM-DD HH-mm> <герой без npc_dota_hero_> (match <id>)\`, для `matchid`=0 — `demo` вместо `match <id>`.
- Клип: `[HH.MM.SS-HH.MM.SS] <n> kill|kills[ + <m> assist|assists] (KDA k-d-a).mp4`. Отрицательное игровое время: `-00.00.40`.
- `match.json`: id, герой, steamid, старт, события (тип, clock_time, wall time), клипы (путь, границы, статус ffmpeg).

## 6. Панель настроек в OBS (obs_properties)
Папка клипов (path dialog, по умолчанию `C:\Highlights`) · Порт GSI (3220) · Окно серии (15) · Хвост одиночного (10) · Хвост серии (15) ·
Секунды до (10) · Путь к ffmpeg (автопоиск в PATH, по умолчанию `C:\ffmpeg\bin\ffmpeg.exe`) · Учитывать ассисты (вкл) ·
Кнопка «Установить GSI-конфиг в Dota» · Статус: «GSI: пакет N с назад / нет», «Буфер: активен/нет», «Последний клип: …».

## 7. Состав репозитория
```
obs_dota_kill_clipper.py   # точка входа для OBS: UI, события OBS, таймеры; импортирует пакет ниже
killclipper/
  gsi.py        # HTTP-приёмник + парсинг пакета в состояние
  series.py     # детектор серий (чистая логика, без OBS)
  naming.py     # папки, имена, match.json
  cut.py        # расчёт границ и вызов ffmpeg
  dota_paths.py # поиск Dota через Steam, установка cfg
tests/          # pytest: series, naming, cut (границы), gsi parse
install.ps1     # ставит GSI-cfg, создаёт C:\Highlights, печатает шаги для OBS
README.md, CLAUDE.md, docs/
```
Зависимостей вне стандартной библиотеки нет (obspython даёт OBS; ffmpeg — внешний exe).

## 8. Критерий готовности
1. `pytest` зелёный: серия из 1 / 2 / 3 событий, дабл-килл в одном пакете (+2), ассист внутри серии, окно 15 с, хвост 10/15,
   базовый пакет без событий, смена матча, отрицательное время, именование, границы ffmpeg.
2. OBS 32.2.2 загружает скрипт под Python 3.12 без ошибок в логе; панель настроек показывает статус GSI.
3. Живой прогон (демо-режим или боты): одиночное убийство и серия → в `C:\Highlights\<матч>\` два клипа, длина ≥ 20 с, границы верные,
   `match.json` заполнен, буфер продолжает работать.
4. В публичном репозитории нет токенов, имени пользователя в путях, логов.

## 9. Вне рамок
Клипы смертей, командные убийства, оверлеи поверх игры, публикация куда-либо кроме YouTube, Linux/macOS, нативный C++ плагин.

## 10. Расширение: Shorts и YouTube (утверждено 2026-09-13 ответами пользователя в опросе)

### 10.1 Вертикальный монтаж
- Холст 1080×1920, частота исходника (60 fps): полоса 420 px сверху, игровой квадрат 1080×1080 из центра кадра, полоса 420 px снизу.
- Фон под всем холстом: та же запись, растянутая, размытая и затемнённая (яркость −0.25, насыщенность 0.7).
- CTA сверху и снизу: пути в панели скрипта. Рекомендуемый формат 1080×420 с альфа-каналом
  (ProRes 4444 `.mov`, WebM VP9 alpha, GIF, PNG). Вставка вписывается в полосу с сохранением пропорций и зацикливается на длину клипа.
- Музыка: случайный трек из папки (подборка ~150 энергичных треков Kevin MacLeod, CC BY 4.0, скачивает `tools/fetch_music.py`).
  Звук игры сохраняется, музыка идёт с громкостью из панели, обрезается под клип с затуханием 1.5 с. Атрибуция трека всегда в описании.
- Горизонтальный клип остаётся; вертикальный кладётся в `<папка матча>\shorts\` с тем же именем.
- Кодирование: h264_nvenc, при ошибке libx264; ffmpeg с приоритетом ниже обычного; рендеры идут строго по одному.

### 10.2 Публикация на YouTube
- Только Techies: на других героях клипы не записываются вовсе.
- Канал «Betreazen highlights Dota 2» (`@Betreazen_highlights`). Вход кнопкой «Log in to YouTube» в панели, токен сохраняется;
  токен другого канала отклоняется и удаляется.
- Текст готовится сразу, как готов горизонтальный клип (до рендера), из словарей `killclipper/seo_dictionary.json`.
  Язык ru/en выбирается случайно на каждое видео и общий для названия и описания; теги смешанные.
- Название: хук по числу убийств (1 / 2 / 3 / 4 / 5+ / только ассисты) + ` | Dota 2 <год> | Betreazen highlights Dota 2`, не длиннее 100 символов.
- Описание до 5000 байт, заполняется почти целиком: хук, вступление с числом убийств и KDA, абзацы, призыв, ключевые слова,
  15 хештегов (первые `#Dota2 #Techies #Shorts`), атрибуция музыки.
- Теги до 500 символов по правилам YouTube (запятые и кавычки у тегов с пробелом считаются), приоритетный список + теги с годом.
- Загрузка сразу после рендера как `private` с `publishAt` в ближайший свободный слот 08:00–22:00 каждые 2 часа (Europe/Minsk),
  не ближе 15 минут. Слотов на сегодня нет — следующий день. Загружается всё, расписание уходит вперёд.
- Плейлисты создаются при первой необходимости, с описанием: «Dota 2» — все видео; «N kill video» — клипы с N убийствами
  (с ассистами тоже); клипы только с ассистами — только в «Dota 2».
- Очередь заданий `%LOCALAPPDATA%\dota-kill-clipper\jobs.json` переживает перезапуск OBS. Рендер повторяется до 3 раз,
  загрузка до 10 раз (пауза растёт до 1 ч), слот при ошибке освобождается.
- Ограничение Google: без аудита проекта YouTube API все загруженные видео остаются приватными, расписание их не опубликует.

### 10.3 Ежемесячный срез
- При первом запуске OBS в новом месяце (когда есть вход в YouTube): публичные видео канала старше 30 дней, просмотры,
  максимум, минимум, медиана.
- Скрываются (`unlisted`, «доступ по ссылке») видео с просмотрами меньше половины медианы, только если в срезе не меньше 8 видео.
  Медиана не зависит от того, насколько выстрелило одно видео. Ничего не удаляется.
- Отчёт `%LOCALAPPDATA%\dota-kill-clipper\reports\review-YYYY-MM.json`, выполненный месяц хранится в `state.json`.
